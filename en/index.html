02. University

B.Sc. in Information Systems at UTFPR, Francisco Beltrão campus — in progress. Outside the classroom, this is where I learned to lead, teach and bring technology to people who need it.

Undergraduate thesis · in production

sabermais — Learning Management System

A learning platform built for equity: it adapts to each student and shows the teacher how the class studies, so the teacher can adapt too. The study profile comes from LASSI, a study-strategies inventory validated in Brazil.

  • Classes, content, assignments, quizzes, forum, grades, attendance and gamification
  • Study plan and study cycle for students; class profile and teaching suggestions for teachers

Technical decisions

  • Secure multi-tenancy: each institution isolated with PostgreSQL Row-Level Security, not only by application filters.
  • Quality: 340+ end-to-end tests against a real database in CI; deploys only on a green pipeline.
  • Responsible AI: data anonymized before reaching the model; the AI explains, but never solves the student’s assignment.
  • Documented architecture: 20+ decisions recorded as ADRs, with alternatives and consequences.

06. How I work

Understand the problem before the code

I gather the rules with the people who will use the system, through objective questions, and record every decision so no one has to re-argue it later.

Tests and CI as a safety net

Every fixed bug becomes a test. Deploys only go out on a green pipeline: types, integration tests and build.

Documentation that follows the code

Architecture decisions as ADRs, a changelog per delivery and written conventions. The next developer (or me in six months) understands the why.

AI with a method

I use AI agents in development within my own process, with project memory, recorded decisions and quality gates. AI speeds things up; responsibility for the result stays with me.
